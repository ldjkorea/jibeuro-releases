# 집으로 Android 배포

[다운로드 페이지](https://ldjkorea.github.io/jibeuro-releases/)

집으로 0.6.3은 1~9호선에서 공식 자료를 대조한 일반·급행 열차와 환승 후보를 비교하고, 공식 실시간 도착·위치·운행 안내를 조회하는 Android 앱입니다.

- 검증된 열차 그룹 11,655개와 방향별 환승 432개를 반영했습니다.
- 자정 표기와 9호선 급행 종착역 해석을 수정해 열차 442개를 복구했고, 성수·신도림 지선 환승 4개를 추가했습니다.
- 서울시 공식 자료의 1~9호선 도착·위치·무정차 안내와 9호선 운행 관련 공지를 연결했습니다.
- 첫 실행에서 업데이트 결과가 화면 초기화보다 먼저 도착해 표시되지 않던 문제를 수정했습니다.
- 앱 시작·복귀 시 공개 버전을 확인하며 다운로드와 Android 설치는 사용자의 선택을 거칩니다.

## 0.6.3 개선

공급 응답 시각 검사, 조회 조건 다중 탭 충돌 방지, 이전 경로 유지·재조회, Android 공식 링크 연결을 보완했습니다. 기존 0.6.2에서 실제 공개 앱 내 업데이트 및 저장 데이터 보존을 전용 Android AVD에서 검증했습니다.

## 설치

APK를 다운로드해 기존 집으로 앱 위에 설치하세요. 기존과 같은 패키지와 서명을 유지했습니다. 업데이트 주소가 없던 이전 후보는 이번 APK를 처음 한 번 직접 설치해야 합니다. Android 8.0 이상이 필요합니다.

## 현재 지원 범위

- 전체 막차·최적 경로는 미확정이며 906개 열차 그룹과 미확인 환승 자료는 제외합니다. 버스·심야버스는 미지원입니다.
- 실시간 값은 계획 경로를 바꾸지 않습니다. 모든 지연·운휴가 확인되는 것은 아닙니다. 오래된 위치와 자료 미제공을 정상 운행·운휴 없음으로 판단하지 않습니다.
- 평택지제·진접·오남·별내별가람의 실시간 역 연결은 미확인입니다.
- 9호선은 2026년 11월 16일 평일 시간표 변경 예고가 있어, 해당 날짜 이후 평일 이용 경로는 새 공식 자료 대조 전까지 보류합니다.
- 실물폰·제조사별 동작은 검증하지 않았습니다.
